# 涨跌实验室（StockLab）

一款 HarmonyOS 的"历史股市模拟器"：在真实发生过的市场里（1929 大崩盘、1987 黑色星期一、2000 互联网泡沫、2008 次贷危机、2015 A股股灾、2016 熔断、2020 疫情熔断）或用算法随机生成的市场里，实时盯盘、买卖、加杠杆、借贷款，体验不同的市场规则与人性。

> 数据为教学演示，关键历史点位取自公开资料，节点之间为插值生成，非精确历史行情，不构成任何投资建议。

## 快速开始

- 开发工具：DevEco Studio（SDK 6.1.1 / API 24）
- 打开 `D:\Stock` 工程，等待 Sync 完成
- 预览器打开 `pages/App.ets`（页面用状态机切换，预览器可直接点击）
- 或连接模拟器 / 真机运行

## 功能

| 模块 | 说明 |
|---|---|
| 历史剧本 | 7 个时代：1929 大崩盘（744 日）、1987 黑色星期一（260 日）、2000 互联网泡沫（723 日）、2008 次贷危机（370 日）、2015 A股股灾（168 日）、2016 A股熔断（131 日）、2020 疫情熔断（84 日） |
| 随机模拟 | 活市场：一次 3~5 只虚构股票（各自独立走势），每天实时生成下一根K线，永不落幕；顶栏可切换当前股票，同一账户现金共用、持仓独立记账；右上角手动结束本局，支持存档续玩；消息以快讯形式出现，5 秒后自动消失，不占用历史现场 |
| 实时盯盘 | 定时推进行情，Canvas 分时曲线自动生长；可分时 / K线双模式切换 |
| 下单面板 | 常驻页面底部，不弹层：一倍保证金 + 杠杆滑块（1~50×）→ 实时显示名义仓位 / 开仓手续费 / 可承受反向波动 → 做多、做空一键成交 |
| 多空双向 | 做多（买）与做空（卖）双向开仓；按持仓自动切换按钮为加多/平多、平空/加空；支持一键平仓；做空敏口上限为净资产 50 倍 |
| 历史现场 | 走到历史事件日自动累积事件卡片，可上下滑动回看 |
| 交易规则 | 手续费、T+1、涨跌停封板、做空，全部按剧本规则生效 |
| 贷款 | 额度 100 万、年化 8%、按交易日复利计息、可借可还；净资产 ≤ 0 爆仓 |
| 杠杆 | 1x / 2x / 5x / 10x / 20x / **50x**，按保证金交易，不足部分自动融资（配资独立于普通借款额度） |
| 存档 | 自动保存当前对局（每 5 个交易日 + 每次交易），主界面可"继续上一局" |
| 结算复盘 | 收益率、最大回撤、交易笔数、胜率、手续费；全程行情曲线标注买卖点；逐笔流水；与"买入持有"对照 |
| 成就系统 | 15 个成就（首次出手 / 逆向思维 / 五十倍狂热 / 归零体验 / 空仓到底 等），实时判定、本机持久化，主界面可查看收集进度；未解锁的成就只显示名字，条件在达成后揭晓 |
| 新手引导 | 首次打开先问「新手 / 老手」：新手进 4 步图文教程，老手直接开始；主界面可随时重看 |
| AI 复盘点评 | 接入兼容 OpenAI 协议的大模型接口，把收益/回撤/胜率/流水交给模型生成个性化点评；未配置 Key 或请求失败时自动退回本地文案 |
| 汇率走势 | 真实数据页：欧洲央行每日参考汇率，美元/欧元/日元/英镑/港币/澳元对人民币；区间 30 天 ~ 一年快捷选择，也可自选起止日；给出期末值、涨跌幅、最高最低与年化波动率 |

## 技术架构

单体应用分五层 + 两个横切关注点：

```
L1 表现层   views/（HomeView / HistoryView / TradeView / ResultView / AchievementView / TutorialView）+ pages/App.ets（状态机入口）
L2 调度层   视图内状态与交互编排（@State / @Prop）
L3 业务层   services/（MarketService 行情、TradingService 交易、RandomScenarioService 随机生成、AchievementService 成就、AiService 大模型、RateService 汇率）
L4 数据层   repository/（IMarketDataSource 接口 + BuiltinScenarioSource 实现）
L5 存储层   core/SaveService（AppStorage + PersistentStorage JSON 快照）
横切 A     core/（Result 统一返回、EventBus 事件总线、AppContext 服务定位）
横切 B     config/（常量与主题色）+ models/（实体接口）
```

目录结构：

```
entry/src/main/ets/
├─ pages/App.ets            唯一入口页，状态机切换九个视图
├─ views/                   九个视图（引导询问 / 教程 / 主界面 / 剧本列表 / 盯盘 / 复盘 / 成就 / 设置 / 汇率）
├─ services/                行情、交易、随机生成、成就、大模型
├─ repository/              数据源接口与内置实现
│  └─ data/                 ArkTS 内置剧本数据（rawfile 不可用时的回退）
├─ core/                    Result / EventBus / AppContext / SaveService
├─ models/                  KLine / Scenario / ScenarioEvent / Account
├─ config/AppConfig.ets     常量与主题色
└─ entryability/            应用入口，装配服务与持久化键
```

关键设计：

- **接口驱动数据源**：`IMarketDataSource` 定义"剧本目录 + 加载剧本"，`BuiltinScenarioSource` 优先读 rawfile，失败自动回退 ArkTS 内置数据（兼容预览器）；
- **规则参数化**：每个剧本自带 `rules`（涨跌停、T+1、费率、能否做空），同一套交易代码跑出不同市场；
- **状态机代替路由**：九视图用 `@State view` 切换，避免预览器不支持 router 的问题；
- **确定性伪随机**：K线高低点用 `Math.sin` 按蜡烛序号派生，重绘不闪烁；
- **单例装配**：`AppContext` 统一创建服务，换数据源只改一行。

## 市场规则

| 规则 | 实现 |
|---|---|
| 手续费 | 买卖双边按 `feeRate` 收取，累计显示 |
| T+1 | 当日买入的仓位冻结，次日可卖 |
| 涨跌停 | 当日涨跌达到限制的 95% 视为封板：涨停买不进、跌停卖不出 |
| 做空 | 仅允许做空的剧本可负持仓，按卖出价记空头均价；做空敏口上限 = 净资产 × 50 倍 |
| 贷款 | 普通借款上限 100 万，日利率 0.032%（年化 8% / 250 交易日），复利计息；杠杆配资另受总债务 5000 万上限约束 |
| 杠杆 | 保证金 = 市值 / 倍数（最高 50 倍）；融资额 = 市值 - 保证金，计入负债（受总债务 5000 万上限约束） |
| 爆仓 | 净资产 = 现金 + 持仓市值 - 负债 ≤ 0 即爆仓 |

## 大模型配置

结算页的 AI 复盘需要一个兼容 OpenAI `/chat/completions` 的接口：

1. 主界面底部 →「模型设置 ›」
2. 点上方任一预设一键填入地址与模型名，再填 API Key
3. 保存后回到结算页，点「生成 AI 点评」

内置预设（均提供免费额度，具体政策以官网为准）：

| 服务 | 模型 | 说明 |
|---|---|---|
| 智谱 GLM-4-Flash | `glm-4-flash` | 免费，国内直连，注册即可用 |
| 本地 Ollama | `qwen2.5:3b` | 完全免费，免 Key，需电脑常开且与手机同一局域网 |

Key 只保存在本机（PersistentStorage），代码中不内置任何密钥；未填 Key 时自动使用本地文案。本地 / 局域网服务（`localhost`、`127.0.0.1`、`192.168.x.x`）不需要 Key。
